# ClipRank

ClipRank is a dynamic, AI-powered social media clipping tool that allows users to easily authenticate with platforms like YouTube, Instagram, and Facebook to generate engaging video clips. 

## Features
- **Multi-Platform Integration**: Connect your YouTube, Instagram, and Facebook accounts seamlessly.
- **AI-Powered Clipping**: Automatically retrieve video data to generate ranked clips.
- **Modern UI**: Built with React, Tailwind CSS, and Framer Motion for a stunning user experience.

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM
- Lucide React

## Getting Started

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation
1. Clone the repository and install dependencies:
   ```bash
   npm install
   ```
2. Copy the example environment file and fill in your API credentials (e.g., Google, Meta client IDs):
   ```bash
   cp .env.example .env.local
   ```

### Running Locally
To start the development server, run:
```bash
npm run dev
```

### Build for Production
To build the app for production, run:
```bash
npm run build
```
